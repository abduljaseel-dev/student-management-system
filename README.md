# Student Management System

A clean and simple Student Management System built using PHP, PDO, MySQL, AJAX, JavaScript, HTML, and CSS.

---

## Features

- Admin Login System
- Session Authentication
- Add Students
- View Students
- Edit Students
- Delete Students
- AJAX Live Search
- PDO Prepared Statements
- Responsive UI Design

---

## Technologies Used

- PHP
- MySQL
- PDO
- AJAX
- JavaScript
- HTML5
- CSS3

---

## Installation

### 1. Clone Repository

```bash
git clone https://github.com/abduljaseel-dev/student-management-system.git
```

### 2. Move Project

Move the project folder into:

```text
htdocs/
```

### 3. Import Database

Import:

```text
database.sql
```

into phpMyAdmin.

### 4. Start XAMPP

Start:

- Apache
- MySQL

### 5. Open Project

```text
http://localhost/student-management-system/
```
